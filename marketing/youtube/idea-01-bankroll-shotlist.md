## How to use this
1. Record VO first (see `script` `>` lines), block by block.
2. Prep every asset in the **Asset Prep Checklist** below.
3. Drop VO on the timeline, then lay each **Visual** over its **Time** window using this table.
4. Add the SFX/motion in the **Motion / SFX** column and the source lower-third in **Source LT**.
5. `[REC]` = screen-record · `[SVG]` = reuse/animate a blog SVG · `[CARD]` = build text card in editor/Canva · `[FX]` = motion-graphic build.

**Aspect:** 16:9, 1920×1080 min (4K if screen-recording the app for crop room). **Fps:** 30. **Safe margins:** keep text off the outer 10% (mobile crop + progress bar).
