## How to apply everything

**Banner image** (`channel-banner.png`):

- It's already 2560×1440 with content inside the 1546×423 safe area — accept the default crop.

**Profile picture:** use the app icon `web/icons/Icon-512.png` (Studio → Branding → Picture). YouTube wants ≥98×98; 512 is fine.

**Description + links + email:** Studio → **Customize channel → Basic info** → paste the blocks above. The first link you add is the one that overlays the banner (make it the UTM'd app link).

**Handle:** set a clean handle if not done — e.g. `@TableLab` (Customize channel → Basic info → Handle).
